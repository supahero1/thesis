# Building

Prerequisites: **Scons**, **GNU Make**, **glslc**, **vips**, **assimp**, **volk**, **stb_image**, **SDL3**, **WiVRn** or **Monado**, **Vulkan**, **OpenXR**.

Building: `make vk` or `make xr`.
